# Ta Te Ti 🎮

Este es un juego simple de **Ta Te Ti (Tres en línea)** para dos jugadores, desarrollado con HTML, CSS y JavaScript.

## Características
- Interfaz simple y visual.
- Dos jugadores se turnan usando **X** y **O**.
- Detecta automáticamente cuando un jugador gana o hay empate.
- Colores distintos para cada jugador: X en azul 💙 y O en rojo ❤️.
- Botón para **reiniciar la partida**.

## Cómo jugar
1. Hacé clic en una casilla vacía para poner tu símbolo (X o O).
2. Los jugadores se turnan hasta que alguien gane o se produzca un empate.
3. Hacé clic en **Reiniciar** para comenzar una nueva partida.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
