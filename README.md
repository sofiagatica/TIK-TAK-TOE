# Ta Te Ti 🎮

Este es un juego de **Ta Te Ti (Tic Tac Toe)** desarrollado en HTML, CSS y JavaScript.  
El juego permite jugar **entre dos jugadores** o **contra la computadora**. Además, lleva un **contador de victorias** para cada jugador.

---

## 🕹️ Características

- Tablero 3x3 interactivo.
- Colores diferenciados para cada jugador:
  - X → Azul
  - O → Rojo
- Contador de victorias acumulado para **Jugador X** y **Jugador O**.
- Modo **contra la computadora**:
  - La computadora juega con O.
  - Elige casillas vacías al azar.
- Botón para **reiniciar partida** sin perder el puntaje.
- Mensajes de turno y ganador.

---

## 💻 Cómo jugar

1. Abrir el archivo `index.html` en un navegador web.
2. Hacer clic en una casilla vacía para colocar tu X u O.
3. Alternar turnos entre jugadores o activar el modo computadora.
4. El juego detecta automáticamente **ganador o empate**.
5. Presionar **Reiniciar** para comenzar una nueva partida sin perder el puntaje.
